轩辕剑外传·苍之涛 同人复刻（非官方、非商业）

运行：双击 czt.exe。
  czt.exe、czt.pck 和 packs 文件夹必须放在同一个目录里。
  packs 里的 common.pck、ch01–ch10.pck（基础数据）和 hd2.pck（2K 画质）默认都带；默认用 2K 画质，可在「设定」里关掉。
  去掉 hd2.pck 可省约 2.1GB，画质变为标清。
  4K 画质：另外下载 hd4.pck（约 4.2GB）放进 packs，并删掉 hd2.pck。两个都在时用 4K。
    4K 的界面和场景贴图是 2K 的两倍清晰度，过场动画暂时还是 2K；显存建议 2GB 以上。

存档、设置和创意工坊 mod 在：%APPDATA%\Godot\app_userdata\轩辕剑外传·苍之涛 同人复刻（非官方）\
  创意工坊：把 .pod 文件放进上面目录下的 mods 文件夹，在游戏「工坊」里点「刷新」，再点「启用」。

手柄：Xbox、PS 等手柄插上就能用（PS 手柄按位置对应：叉 = A，圈 = B，方块 = X，三角 = Y）。
  左摇杆 / 十字键  移动、选择        A  确认、调查        B  取消
  Y / Start        打开主菜单        LB / RB  转镜头      右摇杆  转镜头
  按住 X + 左右    转镜头            按下右摇杆  镜头回正  按下左摇杆  跑 / 走切换
  Back / Share     小地图            战斗中 X 逃跑，Y 自动战斗
