轩辕剑外传·苍之涛 同人复刻（非官方、非商业）

本作不附带任何原版素材，需要你自己的正版《轩辕剑外传·苍之涛》。

第一次运行：
  1. 双击 czt.exe，按提示选择正版游戏的安装目录（里面有 ACT、MAP、Model、Music 等文件夹）。
  2. 点「开始提取」，游戏会从正版目录提取素材（约 4.5GB，十几分钟，只需一次），完成后自动重新启动。
     素材放在 czt.exe 旁边的 extracted 文件夹；这个位置不能写入时（如装在 Program Files）放在下面的存档目录里。
     中途可以取消或关掉游戏，下次启动从中断处继续。提取失败时界面上会显示原因和日志位置（extracted\extract.log）。
  czt.exe、czt.pck 和 extractor 文件夹必须放在同一个目录里。
  以后更新：只需替换 czt.exe 和 czt.pck；如果提取规则有变，游戏会提示重新提取。

高清画质（可选）：另外下载 hd2.pck（2K）或 hd4.pck（4K），放进 czt.exe 旁边新建的 packs 文件夹。

存档、设置和创意工坊 mod 在：%APPDATA%\Godot\app_userdata\轩辕剑外传·苍之涛 同人复刻（非官方）\
  创意工坊：把 .pod 文件放进上面目录下的 mods 文件夹，在游戏「工坊」里点「刷新」，再点「启用」。

手柄：Xbox、PS 等手柄插上就能用（PS 手柄按位置对应：叉 = A，圈 = B，方块 = X，三角 = Y）。
  左摇杆 / 十字键  移动、选择        A  确认、调查        B  取消
  Y / Start        打开主菜单        LB / RB  转镜头      右摇杆  转镜头
  按住 X + 左右    转镜头            按下右摇杆  镜头回正  按下左摇杆  跑 / 走切换
  Back / Share     小地图            战斗中 X 逃跑，Y 自动战斗
