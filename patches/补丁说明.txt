苍之涛 同人复刻版 —— 懒人补丁包 v22
（现场打补丁：版本号始终跟着官方，永远不会被「请更新到 x.x.xx」卡住）
================================================

一、怎么装（就一步）
------------------
把「懒人补丁包.exe」放进游戏根目录 —— 就是有 czt.exe 的那个文件夹
（例如 E:\XuanYuan.Sword.Millennial.Destiny.CHS.Green.Edition）——
然后双击运行即可，它会自动给这个游戏装好补丁，并提示「补丁安装完成」。

* 放错地方（附近找不到 czt.exe）时，它会提示「请把本文件放到游戏根目录再运行」，
  然后等你按任意键退出，不会乱改任何文件。
* 装之前最好先退出游戏；如果游戏开着，它会提示「czt.pck 被占用，请先退出游戏」。
* 装完进游戏，到标题页「设定」里勾上「宽屏」，勾一次就一直记住。

二、作者更新了怎么办
------------------
官方更新会把 czt.pck 换回官方新版（补丁也就没了）。这时把 exe 重新放进游戏根目录
再双击一次就行：它读取的是当前这份官方包，只把补丁脚本注入进去，build 号 / 版本号
仍然是官方的，所以不会再触发更新提示。

三、装完多出什么功能
------------------
* 宽屏：3D 场景铺满窗口（16:9 / 21:9 都填满），800×600 的 2D 界面自动居中，两侧装饰镜像延展。
* 小地图：当前任务的目标用红旗标出，只标「还能触发剧情的地方」——已经触发过的一次性事件
  （调查过的石台、开过的宝箱、对话完换掉事件号的对象）会自动从候选里消失，不会一直挂着旗；
  一张图上有好几处都能推进剧情时，取离主角最近的那处（只算水平距离，不受地形高低影响）；
  目标离得太远、不在小地图窗口范围内时不显示红旗（走近到窗口里就会自动出现）。
  小地图始终居中、汇总整张地图信息，很多地方会自动半透明贴在画面上。
* 对话：多项选择时鼠标指到选项就高亮，点哪项选哪项（原版鼠标没反应、只取第一项）；
  多选对话框改成屏幕居中，不再压到左上小地图。
* 天书「事」页：未完成任务 / 已完成任务 / 历史相关，三个页签直接点切换。
* 快捷键：F5 快速存档到 0 号档（禁存地图提示「现在不能存档!!」）；F6 打开读档页面自己选档；
  C 切换自动剧情（有小提示，鼠标移开淡出，不挡选项）；ESC 直接打开天书卷轴。
* 战斗：挡住人物的装饰网格（木甲工房那种大齿轮平面）自动隐藏，近裁剪面自适应，不再糊角色；
  右下角多倍速按钮 X1 / X1.5 / X2，点一下换档，出战斗自动复位。
* 装补丁时会把游戏版本号对齐到你当前的官方版本（读 update/apply.log 里的更新包号），
  所以更新完再打补丁不会每次启动都提示「发现新版本」；官方真出新版时照常提示、照常能更新。
* 默认开启引擎自带的 3D 物理插值（补丁器会在游戏目录自动写一份 override.cfg）：
  角色移动、场景物件、镜头平移按显示器刷新率补间，35 帧的地图逻辑看起来更顺。
  人物骨骼动作和技能特效序列帧仍是原版帧数，所以变滑的主要是「移动 + 镜头」，不是所有动作。
  想关掉：删掉游戏目录里的 override.cfg 即可。
* 后台默认开启垂直同步、帧率上限 120 帧（不占设定页的位置，进游戏就生效）：
  原版内容只有 27/35 帧，锁 120 帧后帧间隔更稳、也不撕裂。
* Alt+Enter 全屏 / 退出全屏，状态同步进设定页的「全屏显示」勾选框。
* 主菜单「离开」确认框三选项：离开游戏 / 回主菜单 / 取消。
* 主菜单、天书、战斗界面字体加深棕收边，放大不发糊。

四、卸载 / 出问题
------------------
* 卸载：游戏目录里会有一份 czt.pck.beforepatch_日期时间（打补丁前的官方原包），
  把它改名回 czt.pck 覆盖即可恢复官方原版。
* 「Windows 已保护你的电脑」：exe 没有数字签名触发的 SmartScreen，点「更多信息」→「仍要运行」。
* 提示「找不到全部补丁目标脚本」→ 作者改了脚本结构，这版不兼容，别装，等适配版。
* 提示「字节码版本对不上」→ 作者换了 Godot 版本，先别装。
