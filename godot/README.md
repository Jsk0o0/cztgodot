# 轩辕剑外传·苍之涛 同人复刻（Godot 4，非官方、非商业）

**本项目不包含任何原版素材。** 运行时从玩家本机自备的正版游戏目录，以及用 `../tools/` 提取出的目录读取素材。
《轩辕剑外传·苍之涛》全部角色、美术、音乐、剧情等素材的版权，均归大宇资讯股份有限公司所有。

## 运行
1. 安装 Godot 4.7。
2. 在上级目录运行 `make ui text` 提取素材（至少需要界面图和文本）。
3. 在 `local_paths.cfg` 里填写游戏目录和提取目录（这个文件不随项目分发）。
4. 在上级目录运行 `make start`（或 `godot --path godot`）

## 当前内容
- `scenes/splash.tscn`：启动时的同人作品声明（约 5 秒，按任意键跳过）。
- `scenes/title.tscn`：**按原版还原的标题画面**（依据 SWDMD_GB.EXE 0x4701e8 / 0x470660 的逆向结果）：
  - 800×600 原版标题图，按钮用原版的「開始 / 讀取 / 設定 / 離開 / 動畫」，各有常态、选中、按下三态；
  - 按钮纵坐标采用原版坐标表 299/344/389/434/479；
  - 选中某项后，桓远之先睁眼（原版 5 帧动画），然后才执行该项；
  - 音乐用原版标题曲 Fate100.mp3（MAPS.DAT 地图音乐表的 1 号记录）；
  - 「開始」现在只显示开场字幕（原型）；「設定」可调音量和全屏，并显示声明；「動畫」和剧情中的过场视频需要先 `make video`（Bink → Theora，需 `brew install ffmpeg2theora`）；高清版 `make hd-video`（逐帧 Real-ESRGAN ×2，输出到 `extracted_hd/video/`，高清模式下优先使用）。

- `scenes/skill_preview.tscn`：**技能预览**（`make preview`，或 `make preview CHAR=桓远之` / `CHAR=云狐`）。
  - 角色站在战斗场景「晋大地」里，按原版 ATK 招式脚本逐条执行；右上是 4:3 的原版画面，左侧技能列表，下方说明卡；
  - 操作：↑↓ 选择技能，Enter 重播，Tab 切换角色，W 切换武器，右键拖动旋转视角，滚轮缩放，Esc 回到标题；
  - **坐标与画面**：模型、场景、特效都保留游戏原始坐标（我方在 −Z 一侧面朝 +Z，1 米 = 100 单位，站位取自 `camera_pos` 数据）。
    原版是 D3D 左手系，直接在 Godot 里渲染会左右镜像（例：人诛诀的「誅」字反了），所以 3D 画面渲染到 SubViewport 后水平翻转显示；
  - **原版镜头**（勾选「原版镜头」，默认开启）：执行招式里的镜头指令 0x1e–0x2e / 0x3e（逆向见脚本注释与 `tools/battle_vm.json`）：
    眼睛 = 注视点 + Rz(c)·Ry'(b)·Rx(a)·(0,0,−距离)；注视点、角度、距离三个通道各有瞬切 / 匀速 / 指数缓动三种模式；
    视野角按原版投影（焦距 1000 像素，垂直 33.4°）；没有镜头指令的招式用原版默认战斗镜头（注视点 (15,40,−240)、角度 (16,359)、距离 1600）；
    地形剔除背面，与原版一致（原版常贴地仰拍，镜头略低于地面时地形是透明的）；
  - **特效位置**按原版：0x02 默认放在每个目标身上，0x04 之后放一个在战场原点 + 偏移；0x03 从施术者（或 0x4f 指定的挂点）出发，偏移是否随朝向旋转由 0x73 决定；
    特效朝向角默认为 0（按世界轴）；0x35 删除特效；
  - **特效播放**（`scripts/fx.gd`、`scripts/fx_emitter.gd`，数据来自 `make effects`）：
    - 3D 特效模型按 ACT 特效脚本逐帧播放（帧号、颜色、缩放、旋转、偏移），混合方式 = 材质 flags | 当前帧 XF（例：应龙黑龙淡出时转加法）；
    - 公告板骨骼每帧转向镜头；UV 动画改为按帧切换预先生成的网格；
    - 粒子按 Effect.dat 参数模拟；外观是 3D 模型的粒子，每个粒子循环播放自己的 ACT 特效（与原版一致），外观是精灵的仍画成面片；
    - 不开辉光、不做色调映射（原版没有），加法特效叠加后直接截到白色；
  - **其他招式指令**：画面环境色渐变（0x3a，大招压暗场景与角色）、武器拖尾（0x3b）、残影（0x36，参数含义为推测）、
    瞬移到目标（0x6d）、等待（0x19，单位 10 毫秒）、普通攻击开头的随机跳转（按权重随机选一套连招，`--variant=n` 指定）；
  - **节奏按原版**：动作按 ACT 播放表、35 帧/秒播放；跑动速度取自招式脚本；特效在动作的 `g` 记号处放出，`e`/`d` 记号处木桩受击；
  - **武器**：武器物品号就是道具 ACT 号，取它的第 1 号动作模型（原点在剑柄），按原版规则（exe 0x419eee）挂到角色挂点 1，旋转部分整体取负。W 键在该角色能用的全部武器间切换（`--weapon=轩辕剑` 可直接指定）；
  - 每次切换动作前先把骨架复位（Godot 导入时会丢掉等于静止姿势的通道，不复位会残留上一个动作的姿势）；
  - 木桩是占位目标；`set_units_alpha`（淡化其他单位）因为场上没有其他单位，没有实现；
  - 调试：`--skill=断意诀` 自动演示，`--record=目录 [--record-step=0.25]` 连拍整个技能，`--fx-test=8101_7` 在木桩处循环播放特效，
    `--focus=x,y,z`、`--yaw=`、`--dist=` 调整手动视角，`--debug-fx` 打印特效生成信息。

- `scenes/field.tscn`：**正式游戏（地图探索 + 剧情 + 战斗）**。标题「開始」进入；数据由 `make game-data` 生成。
  - 事件脚本解释器 `scripts/field/event_vm.gd`：序章用到的 99 种事件指令都已实现（对白、选项、镜头、角色、换图、旗标、任务、道具、音乐、战斗），表情、地图特效、手持物品、音效也已实现；
  - 地图 `scripts/field/field.gd`：场景按 MAP 头的场景 ACT 取 WLD（权威对应），碰撞用 WLD 地面三角形 + 阻挡盒，NPC 来自 MAPS.DAT 常驻角色表；
    操作按原版：方向键 / WASD 相对镜头移动（默认跑 14、R 切换走 5 单位/帧），按住左键朝鼠标方向走，空格 / 点击 NPC 对话，Q/E、Shift+←→、右键拖动转镜头，Tab 回正；事件框、随机遇敌（遇敌区域 + 步数概率组）；
  - 手持物（事件指令 0x8a，例：开场车芸收云狐时手里的天书残简）挂在角色挂点骨骼上，战斗中嬴诗 / 桓远之拿着当前武器（`tools/export_held.py`）；
  - 地图物件（all_map2 的 ACT 15000+：出入口黄色箭头 16005、宝箱、门等）照常显示，模型在 `Model/OTH*.PLY`，无贴图的靠顶点色；

## 与原版的差异
- 简体 1.04 版 exe 的菜单是用字体画的文字（x=530）；这里用的是图库里原版的按钮图片，水平位置居中于标题字下方。
- 标题画面竹叶飘落（Effect 8001 第 5、6 号）已做。
- 音效：all.snd 已解开，界面、技能 VW 和战斗音效都已接上。
